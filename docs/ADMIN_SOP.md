# ADMIN STANDARD OPERATING PROCEDURES (SOP-01 S.D. SOP-18)

Panduan operasional tanpa menulis kode atau bantuan AI:

- **SOP-01 Tambah Anime Baru:** Content > Anime > New > Isi field > Cek duplikat > Draft > Preview > Publish.
- **SOP-02 Update Episode:** Anime > Episodes > Add/Batch > Verifikasi waktu WIB > Publish.
- **SOP-03 Tambah 3 Server pada 720p:** Episode > Source Matrix > 720p > Tambah 3 varian > Verifikasi link > Publish.
- **SOP-04 Server Down:** Streaming > Health > Inspeksi laporan > Pause varian bermasalah > Pastikan server alternatif aktif.
- **SOP-05 Provider Disallowed / Hak Dicabut:** Rights > Case > Suspend provider/source > Invalidate cache > Catat di audit log.
- **SOP-06 Koreksi Status Subtitle:** Report > Review source > Perbarui tag Sub Indo > Re-verify.
- **SOP-07 Rename Anime & Pasang Redirect:** Anime > Ganti canonical title/slug > Simpan > Sistem membuat redirect 301 otomatis.
- **SOP-08 Pasang Kampanye Iklan Sponsor:** Monetization > Campaign > Pilih slot > Upload gambar & link > Approval > Aktifkan jadwal.
- **SOP-09 Emergency Pause Semua Iklan:** Monetization > Emergency > Pause All Ads > Konfirmasi dengan teks konfirmasi.
- **SOP-10 Kurasi Produk Merchandise:** Merch > Imports > Review > Tolak produk tidak relevan/palsu > Setujui.
- **SOP-11 Proses Keluhan Hak Cipta:** Rights > Ticket > Periksa bukti > Suspend konten > Tanggapi pelapor.
- **SOP-12 Moderasi Akun / User:** Users > Cari user > Review riwayat laporan > Tindakan bertingkat (peringatan/suspend).
- **SOP-13 Penundaan Jadwal Siaran (Delay):** Schedule > Episode > Set status Delayed > Masukkan alasan dan estimasi baru.
- **SOP-14 Rollback Perubahan Admin (Undo):** Object > History > Bandingkan versi > Klik Restore/Undo.
- **SOP-15 Insiden Database / Maintenance:** System > Health > Pasang banner maintenance sitewide > Pause antrean job.
- **SOP-16 Ekspor & Backup Data Rutin:** System > Backup > Unduh arsip terenkripsi (Khusus Owner).
- **SOP-17 Eksperimen Tampilan Beranda:** Growth > Experiments > Atur varian modul > Monitor metrik.
- **SOP-18 Rekonsiliasi Pendapatan Iklan:** Monetization > Reports > Bandingkan invoiced vs received > Ekspor CSV.
